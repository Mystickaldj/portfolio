# Jesse Rowe's Portfolio

Welcome to my portfolio.

I originally got into web development through college and have continued building on those skills through my own projects. Most of my experience has been with JavaScript, TypeScript, React, Node.js, HTML, CSS, SQL, and application development.

## Projects

I built this project to work with application state, user interaction, DOM manipulation, and storing data between sessions.

A JavaScript search and filtering application that displays game results based on what the user searches for and the genre they select.

This project gave me more experience working with dynamic interfaces, filtering logic, and user input.
